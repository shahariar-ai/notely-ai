# Launch checklist

## Blockers (do first)
- [ ] Run `supabase_usage.sql` in the Supabase SQL editor (usage cap)
- [ ] Push approved commits; confirm the live app loads and a full transcribe works
- [ ] Decide on the ffmpeg problem in the Windows recorder (the exe needs ffmpeg installed, see report)
- [ ] Confirm Gemini API quota/billing can survive a launch-day spike
- [ ] Confirm the Supabase `audio` bucket privacy setting (see report)

## Assets
- [ ] 5-8 screenshots (see 04_gallery_plan.md)
- [ ] Thumbnail, optional demo video/GIF
- [ ] Pick tagline (01), paste description (02)
- [ ] Set the GitHub repo homepage to the live URL (done via `gh repo edit`, see report)

## Product Hunt
- [ ] Create/verify your PH account and maker profile
- [ ] Schedule the launch (12:01 AM Pacific time; Tue-Thu are usually busiest)
- [ ] Add topics, links, and the first comment (03)
- [ ] Tell friends to leave honest comments, don't ask for upvotes

## Launch day
- [ ] Post the maker comment immediately
- [ ] Reply to every comment quickly
- [ ] Watch app logs, Gemini quota and Supabase usage
- [ ] Share on LinkedIn/X/Facebook groups/Bangladeshi dev and student communities
